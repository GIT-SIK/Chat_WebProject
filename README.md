### :book: 프로젝트 소개
1:1 실시간 채팅과 할 수 있는 채팅 웹 프로젝트입니다.

채팅 또한 친구 기능을 추가하여 채팅 가능 범위 설정과 친구 검색 공개, 비공개를 설정을 제공하여 사용자에 맞는 유저와 대화할 수 있습니다.

<br>

### :bookmark_tabs: 프로젝트 기능
\- 메인 페이지
* 최근 대화방 목록 제공
* 대화 건수, 친구 수, 친구요청 건수 제공

\- 친구 기능
* 친구 검색, 추가, 거절, 삭제

\- 채팅 기능
* 1:1 실시간 채팅 (Socket 기반)
  
\- 알림 기능
* 친구 요청에 따른 실시간 알림

\- 마이페이지
* 친구 검색 공개 설정
* 메시지 수락 여부 설정
